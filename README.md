### 🚀 Featured projects

**[AI-Receptionist](https://github.com/Maksopinto/AI-Receptionist)**: an AI administrator for small businesses in Telegram. It answers clients from the business's own information, books appointments into Google Sheets and notifies the owner instantly. Red-teamed against prompt injection, with atomic Redis rate limiting and graceful degradation.
`n8n` `Claude` `Telegram` `Google Sheets` `Redis` `Docker`

**[DocChat](https://github.com/Maksopinto/DocChat)**: a desktop RAG app. Upload any document and ask questions about it, online with Claude or **fully offline** with a local LLM (llama.cpp) for networks without internet access. Ships with a Windows installer.
`Python` `RAG` `llama.cpp` `Claude`

**[FamilyBudget](https://github.com/Maksopinto/FamilyBudget)**: a Telegram bot for family budget tracking in plain language. The LLM understands, the code computes: every model output is validated, and all numbers come from SQL.
`Python` `aiogram` `Claude` `SQLite`
